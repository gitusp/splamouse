# Splamouse

プロコン・ジョイコンをマウスとして使うことができるようになります。  
操作感はSplatoonに寄せています。(ジャイロエイムできます。)

https://github.com/gitusp/splamouse/assets/2055516/c113f2e3-12b8-4624-8700-a07d4c96e296

## 機能一覧

| 制御         | 振る舞い                                                     |
|--------------|--------------------------------------------------------------|
| モーション   | マウス移動（ジャイロエイム）                                 |
| L-スティック | マウスホイール                                               |
| R-スティック | マウス移動                                                   |
| ボタン       | [設定ファイル](#設定)で割り当てます(デフォルトでは何もしません) |

## 使い方

- プロコン・ジョイコンをコンピューターに接続します。
    - **プロコンはUSB接続がおすすめです。** macOS Sonoma以降、Bluetooth接続では入力の遅延が目立ちます。
        - データ通信に対応したケーブルを使ってください。充電専用のケーブルでは動きません。
        - ケーブルを挿した後、ボタンを押してコントローラーの電源を入れてください。
    - ジョイコンはBluetoothで接続します。
- [Releases](https://github.com/gitusp/splamouse/releases)から最新版をダウンロードします。
    - Apple Silicon(splamouse-macos-apple_silicon.zip)とx86_64(splamouse-macos-x86_64.zip)のバイナリがあります。
- ダウンロードしたzipをダブルクリックして解凍します。
- 解凍した実行ファイルを**右クリックの「開く」から**開きます。
    - セキュリティダイアログが表示されますが、許可してください。
    - 実行するとターミナルのウィンドウが表示されます。
    - ターミナルがマウス操作のためのアクセシビリティ許可を要求するので、許可してください。
- 以上の手順で、コントローラーでカーソルを操作できるようになります。 :tada:
- ボタンを使うには、[設定](#設定)を参考に設定ファイルを作ってください。

### 設定

`~/.config/splamouse/config.toml` に設定ファイルを置いて、感度とボタンの割り当てを指定します。(`XDG_CONFIG_HOME` を設定している場合は `$XDG_CONFIG_HOME/splamouse/config.toml` です。)  
ボタンはデフォルトでは何も割り当てていないので、設定ファイルに書いたボタンだけが動きます。感度は書かなければ 0.0(標準)です。

以下は、以前のバージョンと同じ割り当てにする設定例です。

```toml
[sensitivity]
# -5.0 から 5.0 の間で指定します。0.0 が標準です。
gyro = 0.0
stick = 0.0

[buttons]
a = "cmd+right"         # ブラウザの進む
b = "cmd+left"          # ブラウザの戻る
x = "cmd"
y = "shift"
l = "alt"
r = "click:right"       # 離した時に右クリック
zl = "hold:left"        # ドラッグ
zr = "click:left"       # 離した時に左クリック
minus = "cmd+w"         # ブラウザのタブを閉じる
plus = "cmd+r"          # ブラウザのリロード
left = "ctrl+shift+tab" # 前のタブ
right = "ctrl+tab"      # 次のタブ
down = "cmd+c"          # コピー
up = "cmd+v"            # 貼り付け
lstick = "none"
rstick = "enter"        # R-スティックを押す
capture = "cmd+z"       # 元に戻す
home = "cmd+shift+z"    # やり直し
```

割り当てられる値は以下のとおりです。

| 値                   | 振る舞い                                          |
|----------------------|---------------------------------------------------|
| `"cmd+shift+z"` など | 押している間キーを押す(`+` で繋げる)              |
| `"hold:left"`        | 押している間マウスボタンを押す(ドラッグ)          |
| `"click:left"`       | 離した時にクリック                                |
| `"center"`           | ポインタをメインディスプレイの中央へ滑らかに戻す  |
| `"none"`             | 何もしない(書かなかった場合と同じ)                |

- キー: `cmd` `shift` `ctrl` `alt`(`opt`)、`a`〜`z` `0`〜`9` と記号(US 配列での位置のキーが押されます)、`left` `right` `up` `down` `enter` `tab` `space` `esc` `backspace`(⌫) `delete`(⌦) `home` `end` `pageup` `pagedown` `f1`〜`f20`
- マウスボタン: `left` `right` `back` `forward`

設定ファイルは起動時に読み込みます。誤りがあると、誤りの箇所を表示して、直されるまで待ちます。

### ログイン時に自動で起動する

コントローラーが繋がっていない間も含めて、splamouseをバックグラウンドで動かし続けられます。ターミナルから以下のように登録してください。

```sh
splamouse install
```

- すぐに起動し、以降はログインするたびに起動します。コントローラーを接続すると自動で繋がります。
- ターミナルアプリではなくsplamouse自身にアクセシビリティの許可が求められるので、許可してください。
- 同時にターミナルからsplamouseを起動しないでください。
- 実行ファイルは`install`したときの場所に置いたままにしてください。移動・更新したら、もう一度`splamouse install`を実行してください。
    - 更新後は以前のアクセシビリティの許可が効かなくなることがあります。カーソルが動かない場合は、一覧から「−」でsplamouseを削除してから許可し直してください。
- ログは`~/Library/Logs/splamouse.log`に出力されます。
- 再起動するには: `launchctl kickstart -k gui/$(id -u)/com.github.gitusp.splamouse`
    - 設定ファイルを変更したら、再起動してください。
- 停止するには: `splamouse uninstall`

## Tips

- 起動時に、読み込んだ設定ファイルと、USBとBluetoothのどちらで接続したかが表示されます。
- カーソルが動かない場合は、splamouseを起動したターミナルアプリにアクセシビリティの許可があるか確認してください(システム設定 > プライバシーとセキュリティ > アクセシビリティ)。
- ある程度操作の間隔が空いてしまうと、コントローラーの接続が切れる可能性があります。
    - ボタンを押したりスティックを回すと、再接続されることが多いです。
- もし接続の問題が解決しない場合は、コントローラーを再接続し、このプログラムを再起動してください。
    - 再接続時、デバイスを一度削除するとより確実です。
